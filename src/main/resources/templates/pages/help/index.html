Accessibility controls

Select Accessibility at the top right of every page to open the accessibility controls. Your choices are remembered in this browser until you select Reset all.

Dark contrast
Shows light text on a dark background.
Invert
Inverts the colours of the page.
Saturation
Shows the page in shades of grey, for users who find colour distracting.
Text size increase / decrease
Makes all text up to 50 per cent larger, or slightly smaller.
Highlight links
Underlines every link and gives it a yellow background.
Hide images
Hides the photographs in the main content, to reduce distraction.
Big cursor
Shows a larger mouse pointer.

Other help:

  • Select Skip to main content (or press Tab once after the page loads) to jump past the menus.
  • Every page can be used with the keyboard alone: Tab moves between links and buttons, Enter activates them, and Esc closes an open menu.

Viewing documents

Reports, leaflets and newsletters on this website are in Portable Document Format (PDF). Every link shows the file format and size before you download it. Current web browsers open PDF files directly; you can also use any PDF reader, such as the free Adobe Acrobat Reader(external website).
