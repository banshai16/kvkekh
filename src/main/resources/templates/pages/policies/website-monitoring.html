The website is monitored to make sure it remains available, performs well, and stays compatible and accessible for all users. Monitoring covers:

  • Availability and performance: the hosting team at the National Informatics Centre monitors the server and is alerted if the website stops responding.
  • Functional defects and broken links: pages and links are checked during each content review; visitors can report problems through the feedback form.
  • Accessibility and compatibility: the website is tested against the Guidelines for Indian Government Websites (GIGW 3.0) and WCAG 2.1 level AA before each significant change, and on current versions of common browsers and mobile devices.
  • Security: software is kept up to date, and the website is audited by a CERT-In empanelled auditor before launch and after major changes.
  • Feedback: feedback from visitors is reviewed and used to improve the website.
