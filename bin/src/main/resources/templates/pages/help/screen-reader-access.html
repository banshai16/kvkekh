Assistive technologies help people with visual, hearing, mobility or learning impairments to use websites. Screen readers convert the text on a page into synthesised speech or braille, so that visually impaired users can listen to and navigate its content.

This website is built to work with screen readers: pages use proper headings and landmarks, images have text alternatives, links and buttons have descriptive names, and every function can be used from the keyboard.
