Besides the accessibility controls on this website, every modern browser lets you enlarge pages and text for all the websites you visit. Menu names may differ slightly between browser versions.

Zoom with the keyboard (all desktop browsers)

  • Zoom in: Ctrl + + (on a Mac, Cmd + +)
  • Zoom out: Ctrl + − (on a Mac, Cmd + −)
  • Return to normal size: Ctrl + 0 (on a Mac, Cmd + 0)

You can also hold Ctrl and turn the mouse wheel.

Google Chrome

Open Settings, then Appearance, and set Font size and Page zoom. Under Customise fonts you can also set a minimum font size.

Microsoft Edge

Open Settings, then Appearance, and change Zoom or, under Fonts, the font size. Edge's Immersive Reader (in the address bar, or F9) shows a page as plain, enlargeable text and can read it aloud.

Mozilla Firefox

Open Settings, then General. Under Zoom choose a default zoom, and tick Zoom text only to enlarge text without images. Under Fonts, select Advanced to set a minimum font size.

Safari (Mac)

Open Settings, then Websites, and choose a Page Zoom. Under Advanced, you can tick Never use font sizes smaller than.

Phones and tablets

  • Android: pinch to zoom, or in Chrome open Settings, then Accessibility, and adjust Text scaling.
  • iPhone and iPad: pinch to zoom, or in Safari tap the aA button in the address bar to change text size. For all apps, open Settings, then Accessibility, then Display & Text Size.
