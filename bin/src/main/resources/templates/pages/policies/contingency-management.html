This plan describes how the website is kept available and restored if something goes wrong.

Content errors

If incorrect or unapproved content is published, it is removed or corrected immediately by the Web Content Manager on the instruction of the Senior Scientist and Head.

Security incidents

If the website is defaced or compromised, it is taken offline and the National Informatics Centre and CERT-In are informed. The website is restored from a verified backup only after the cause has been found and fixed.

Data and server failure

The website's content, media files and database are backed up regularly by the hosting team, so that the website can be restored on another server if the hosting server fails.

Natural disasters and other emergencies

The website is hosted by the National Informatics Centre, whose data centres have their own disaster recovery arrangements.
